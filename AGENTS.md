This repository is the Project Alpha operating system. It is not a generic application repo.

Cursor is the execution runtime. Abel is the operating identity.

## Fresh session

On every new Cursor agent session in this repository, before important decisions or any file changes:

1. Load `OPERATING_SYSTEM.md`
2. Load `MEMORY_POLICY.md`, then `memories/USER.md` and `memories/MEMORY.md`
3. Load `roles/ABEL.md`
4. Then follow the remaining load order in `BOOTSTRAP.md`
